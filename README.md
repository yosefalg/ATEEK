# عتيك — ATEEK

## التحديث الحالي

راجع UPDATE-2.md للتغييرات وحدود النسخة الثانية. المفضلة وإعلاناتي والعروض
والمحادثات والإعدادات تعمل محليًا. جميع الرسائل والعروض مسودات ولا تُرسل إلى مستخدمين.
تم اجتياز 13 اختبارًا للأسعار وفحص TypeScript وتصدير حزمة Android؛ لم يُختبر على هاتف فعلي ولم يُنتج APK.

تطبيق سوق عربي أولًا لبيع وشراء التحف والخردة والسكراب والأغراض المستعملة والجديدة.

## الموجود في النسخة 1.0

- واجهة عربية RTL بهوية بصرية خاصة بعتيك.
- الرئيسية، الأقسام، البحث والفلاتر.
- صفحة تفاصيل لكل سلعة.
- المفضلة مع حفظ محلي دائم.
- إضافة إعلان حقيقي مع صورة من الهاتف.
- تقديم عرض سعر وحفظه محليًا.
- واجهات المحادثات والحساب الشخصي.
- إعداد EAS جاهز لإنتاج APK تجريبي أو AAB للمتجر.

## التشغيل

```bash
npm install
npx expo start
```

التطبيق متصل الآن بمشروع Supabase الحقيقي عبر `src/cloud`. قاعدة البيانات مهيأة في `supabase/migrations`، وتسجيل الحسابات والصور والإعلانات والمفضلة والمحادثات والعروض والتقييمات تمر عبر Auth وRLS وStorage.

## بناء APK

```bash
npm install
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

لأمر Replit الجاهز راجع `REPLIT-BUILD.md`.

## ما يلزم قبل الإطلاق العام

النسخة الحالية أصبحت متصلة بقاعدة بيانات حقيقية. ما زال الدفع والشحن والتحقق الحكومي ورسائل SMS وواجهة الإدارة المتقدمة خارج النسخة الحالية وتحتاج خدمات تجارية وإعدادًا مستقلًا.
